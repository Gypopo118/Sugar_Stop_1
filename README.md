# ХЕ-трекер — PWA для учёта углеводов по фото

MVP: фото тарелки (+рука для масштаба) → DeepSeek Vision → углеводы, ХЕ, ГИ, ГН, ккал, БЖУ.
Только еда и ХЕ — без расчёта дозы инсулина.

## Структура

```
public/            статика PWA (index.html, style.css, app.js, manifest.json, sw.js, иконки)
functions/api/     Cloudflare Pages Functions (= Workers) — серверная часть
  analyze.js       POST /api/analyze — вызывает DeepSeek, возвращает разбор по блюдам
  settings/key.js  POST/DELETE /api/settings/key — хранение своего API-ключа (зашифрован в KV)
functions/_lib/    вспомогательный код (AES-GCM для шифрования ключа)
wrangler.toml      конфигурация Pages-проекта
```

## Деплой на Cloudflare Pages

1. Установить Wrangler и залогиниться:
   ```
   npm install -g wrangler
   wrangler login
   ```

2. Создать Pages-проект (один раз):
   ```
   npx wrangler pages project create xe-tracker
   ```

3. Задеплоить приложение:
   ```
   npx wrangler pages deploy public --project-name=xe-tracker
   ```

Никаких серверных секретов, баз данных или KV настраивать не требуется — приложение полностью автономно.

## Установка на смартфон (PWA)

* **На Android:** при открытии сайта в браузере внизу появляется кнопка «Установить на рабочий стол» (вызывает системную установку PWA).
* **На iPhone (Safari):** кнопка внизу открывает подсказку: кнопка «Поделиться» [↑] → «На экран «Домой»».
* При запуске из созданного ярлыка на рабочем столе приложение работает в полноэкранном режиме (standalone), и кнопка установки автоматически исчезает.

## API-ключи и конфиденциальность

В приложении изначально **нет серверных ключей**.
Каждый пользователь на своём смартфоне в Настройках указывает свой API-ключ (для DeepSeek Vision или Gemini 3.7 Flash).
* Ключ хранится исключительно на устройстве пользователя в `localStorage` браузера.
* При анализе ключ передаётся в запросе напрямую к модели.
* Сервер не сохраняет ключи, баланс владельца проекта защищен от расходования другими пользователями.
* При очистке данных сайта/кэша в браузере ключ потребуется вставить повторно.

## Что дальше (не входит в MVP)

- Синхронизация дневника между устройствами (сейчас — только localStorage).
- Кэширование фото за пределами localStorage (сейчас фото в дневнике хранятся
  как base64 в localStorage — при большом числе записей стоит перейти на
  IndexedDB или R2, лимит localStorage на iOS Safari ≈ 5–10 МБ).
- Расчёт дозы инсулина — сознательно не реализован.
